# 更新紀錄

每個版本一節，標題是 `## <版本>`（跟 package.json 的 version 一樣），新的在上面。
推 tag `extension-v<版本>` 時，發布流程把這一節放進 GitHub release 的說明（`scripts/release-notes.ts`）；
沒有這一節就不會建立 release，也不會送商店審核。開發中的改動直接寫在下一個版本的那一節。

## 0.1.1

### 新功能

- 設定頁：可以設定短網址和貼文的預設有效期限、貼文預設語言、建立後是否自動複製網址、是否預設勾選閱後即焚。從視窗右上角的齒輪打開
- 和 qzz.tw 網站同步：建立過的紀錄和設定會在擴充功能與網站之間自動同步（打開擴充功能或網站時），刪除也會同步。同步只在瀏覽器裡進行，不會上傳
- 閱後即焚的貼文：第一次打開後就從伺服器刪除；貼到 Discord、LINE 等服務產生預覽時不會用掉它
- 在圖片、影片或音訊上按右鍵，就能縮短它的網址
- 貼文的語言選單改從 qzz.tw 取得，之後新增語言不必等擴充功能更新

### 變更

- 預設有效期限改為 1 天：短網址原本是永久、貼文原本是 30 天（可在設定頁調整）
- 右鍵選單只在 http / https 的連結上出現（mailto: 等連結不能縮短）
- 列表標題改為「這個瀏覽器建立過的」，還沒有紀錄時會顯示說明

### 相容性

- 0.1.0 建立的紀錄更新後會保留，原本的刪除碼也照樣能用
- 權限和 0.1.0 相同，更新時不需要重新同意

## 0.1.0

### 功能

- 一鍵縮短目前分頁的網址，結果自動複製到剪貼簿
- 在連結或網頁上按右鍵縮短；選取文字後按右鍵建立貼文（保留換行與縮排）
- 有效期限：1 小時、1 天、7 天、30 天或永久
- 列出這個擴充功能建立過的連結與貼文，可以複製或刪除，過期的會自動清除
- 建立短網址前會經過 Google Safe Browsing 檢查
